# Decision records

These records describe the design Diffra is moving to. They were written afresh on
2026-11-11 and replace the earlier records 0001 to 0010, which git history keeps. A
record says what is decided, what is still open, and how far the current code is from
the decision. Most decisions are not built yet; the [feature status](../README.md#feature-status)
table says what exists today.

| --- | --- |

| [0002](0002-project-file-and-datasets.md) | The project file and datasets |
| [0003](0003-comparison-history-and-noise.md) | Comparison point, history window and noise |
| [0004](0004-records-integrity-and-storage.md) | Records, integrity and storage |
| [0005](0005-surface-do-not-enforce.md) | Surface, do not enforce |
| [0006](0006-pr-output-and-attention-levels.md) | Pull request output and attention levels |

| [0008](0008-optional-events-and-telemetry.md) | Optional event and telemetry output |
| [0009](0009-dependencies-and-extensions.md) | Dependencies and extensions |

The terms used here (dataset, project, record, bundle, history, comparison, rule, finding,
attention level) are defined in the [glossary](../glossary.md).

A new record takes the next number. A record that is replaced is deleted in the same
change that adds its replacement, and every link to it is updated.
